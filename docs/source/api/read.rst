Data Reading Functions
======================

``massphoto`` supports reading mass photometry movies from standard acquisition formats,
including HDF5-based recordings (``.mp``, ``.mpr``), multi-page TIFF (``.tif``, ``.tiff``),
National Instruments TDMS (``.tdms``), and HDF5 containers (``.h5``).

.. tip::
   **Need support for a new camera or file format?**
   If you work with custom interferometric setups, non-standard cameras, or proprietary file formats,
   please `open an issue on GitHub <https://github.com/thielec/massphoto/issues>`_ to request support
   or share a sample recording!
